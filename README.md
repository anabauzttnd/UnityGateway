# UnityGateway

UnityGateway is a distributed, real-time platform engine that enables scalable, auto-scaling architecture for concurrent processing.

The key benefits of using UnityGateway include:

- UnityGateway is a distributed, real-time
- platform engine that enables scalable,
- auto-scaling architecture for concurrent processing

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/UnityGateway.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

UnityGateway is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
